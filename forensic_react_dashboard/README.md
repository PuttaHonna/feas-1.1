# Forensic Investigator React Dashboard

Run with Node.js installed:
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

To add to an existing React project, copy `src/App.jsx` and `src/styles.css` into its `src` directory and run `npm install lucide-react jspdf`.

The background is a lightweight CSS Lightfall-inspired effect for immediate use. To install the actual React Bits component in your existing React project, run:
```bash
npx shadcn@latest add @react-bits/Lightfall-JS-CSS
```
Follow the generated component's usage instructions and replace the `Lightfall` component in `App.jsx` if desired.

Demo workflow results are placeholders, not model predictions. Connect validated trained models before enabling real inference.
